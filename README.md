# dsh-chinese
DSH 全中文模式插件，让 Agent 的思考输出、工具定义、工具调用、Web 工具卡片全部简体中文化。  DSH 原生不支持工具名称、参数键本地化，本插件不直接修改原有工具源码，采用**中文别名工具 + 参数双向翻译**方案：在 Agent 上下文注册全套中文工具别名，模型看到工具名、描述、参数键均为中文；调用时内部自动把中文参数键转回原始英文，转发给缓存的原生工具实现，保留原有执行逻辑、输出渲染与错误处理，不破坏原有契约，同时隐藏对应的英文原生工具。  仅对工具层做本地化，复用 DSH 客户端内置中文语言包，不强制篡改用户界面语言偏好，可配置开关控制语言策略、中文工具、原名隐藏、中文工具速查表等能力。支持渐进降级，不在映射表内的第三方 / MCP 工具会保留原样，不会报错。
